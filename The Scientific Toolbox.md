### Tips, tricks and snippets
This is a repository for storing useful tips, tricks and templates for code. This will include R code for running and interpreting stats models as well as Python code for other modelling and whatever else will be useful to remember or have a template for.

This template is created using [Obsidian][https://obsidian.md/], a free markdown visualisation/note-taking tool. For full functionality, download this into an Obsidian vault.
