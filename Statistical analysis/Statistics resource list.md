This is just a list of useful statistics resources that I use.

* [Statistical Rethinking](https://github.com/rmcelreath/stat_rethinking_2024) Richard McElreath's very useful book and resources
* [Statistical Rethinking using brms](https://bookdown.org/ajkurz/Statistical_Rethinking_recoded/)
* [dagitty](https://www.dagitty.net/dags.html)  Software for creating causal diagrams to make sure your linear models are telling you what you think they're telling you
