If you have (accidentally or otherwise) set it up so that R automatically updates and periodically find yourself weeping tears of frustration when the lines and lines of code you wrote last month are now entirely non-functional because the packages you used no longer work with the latest R update, then fear not (or fear less, at least). There is a way to get back older versions of R that work how you expect.

There is an app called [RSwitch](https://rud.is/rswitch/). RSwitch allows you to use any of your installed R versions just by changing a setting.

How to switch R version (tested for MacOS Tahoe):
1. Download RSwitch zip from the [website](https://rud.is/rswitch/).
2. Unzip it.
3. Open the RSwitch application. RSwitch doesn't have a GUI or anything so it'll just show up as a menu item in the top right corner of the screen. If you click on this, you'll get some options. Mine looks like this:
4. Your installed versions of R should appear and you can just click the one you want, open RStudio and stop crying.![[RSwitch-screenshot.png]]
